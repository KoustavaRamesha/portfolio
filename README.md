# KV — Terminal Portfolio

A retro interactive terminal-style developer portfolio built with HTML, CSS, JavaScript, and Tailwind CSS.

## 🚀 Features

- **Interactive Terminal UI**: Retro CRT monitor overlay, scanlines, boot sequence animation, sound toggle.
- **Interactive Commands**: `help`, `about`, `skills`, `projects`, `experience`, `achievements`, `duck`, `contact`, `clear`.
- **Side Schematic Panel**: Live profile quick-links, resume download button, and dynamic GitHub contribution heatmap.
- **Easter Eggs**: Duck mascot helper & interactive Bug Squasher game.
