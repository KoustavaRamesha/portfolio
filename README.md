# KV — Terminal Portfolio

A retro interactive terminal-style developer portfolio built with HTML, CSS, JavaScript, and Tailwind CSS.

## 🚀 Features

- **Interactive Terminal UI**: Retro CRT monitor overlay, scanlines, boot sequence animation, sound toggle.
- **Interactive Commands**: `help`, `about`, `skills`, `projects`, `experience`, `achievements`, `duck`, `contact`, `clear`.
- **Side Schematic Panel**: Live profile quick-links, resume download button, and dynamic GitHub contribution heatmap.
- **Easter Eggs**: Duck mascot helper & interactive Bug Squasher game.

## ⚡ Deployment on Vercel

This portfolio is static and ready to deploy to Vercel with zero configuration required.

### Method 1: Import via Vercel Dashboard (Recommended)

1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **Add New...** -> **Project**.
3. Select and import your GitHub repository (`KoustavaRamesha/portfolio`).
4. Keep the default settings (Framework Preset: **Other**) and click **Deploy**.

### Method 2: Deploy via Vercel CLI

```bash
npm i -g vercel
vercel
```

## 🛠️ Local Development

Open `index.html` directly in any web browser or serve it using Live Server:

```bash
npx serve .
```
